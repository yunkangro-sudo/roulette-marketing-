# 미니게임 마케팅 툴 — 마케팅 실행 기획서

**조건 요약**: 판매 대상 하이브리드(소상공인 직접 + 대행사 B2B) / 소액 광고비 + 소수 인력 / 1~3개월 내 첫 계약·매출 필요

---

## 0. 한 줄 정의

"내 대행사 고객 3곳에서 만든 실측 성과 데이터"를 무기로, 온라인 오가닉 콘텐츠와 오프라인 상권 영업으로 소상공인 직판을 뚫고, 동시에 그 데이터를 들고 대행사 채널에 B2B 제휴를 제안하는 **증거 기반 하이브리드 확산 전략**.

---

## 1. 목표와 성공 기준 (KPI)

| 기간 | 단계 | 핵심 목표 | 측정 지표 |
|---|---|---|---|
| 1~2주 | 파일럿 | 실사용 매장 3~5곳 확보 | 계약 완료 매장 수 |
| 3~6주 | 증거 확보 + 오가닉 확산 | 파일럿 성과 데이터화, 콘텐츠 발행 | 재방문 전환율, 콘텐츠 조회수/저장수 |
| 6~12주 | 직판 확대 + B2B 제휴 | 유료 전환 매장 10곳+, 대행사 제휴 1~2곳 | 유료 계약 수, MRR, 제휴 미팅 성사 수 |

**1~3개월 현실적 목표선**: 유료 계약 매장 10~15곳, 대행사 제휴 논의 1~2건 시작. (신규 SaaS가 3개월 내 대규모 매출을 내는 건 드물어서, 이 시기 KPI는 "매출 극대화"보다 "재현 가능한 판매 공식 확보"로 잡는 게 현실적이에요.)

---

## 2. 타겟

- **1차 타겟 (직판)**: 윤님 대행사가 이미 관리 중인 기존 클라이언트 — 신뢰가 이미 있어서 파일럿 설득 비용이 0에 가까움. 여기서 얻은 재방문율·매출 데이터가 이후 모든 마케팅의 핵심 자산이 됨.
- **2차 타겟 (직판 확대)**: 파일럿과 유사한 업종·상권의 소상공인 (음식점·카페·미용실). 특히 "손님은 많은데 재방문 관리가 안 되는" 매장 — 이미 위드픽 같은 획득형 툴을 쓰다가 정체된 곳이 전환 확률 높음.
- **3차 타겟 (B2B)**: 소규모~중견 로컬 마케팅 대행사. 이들은 이미 소상공인 고객 풀을 갖고 있어서, 제휴만 성사되면 영업 없이 확산됨. 단, "우리 매출을 뺏는 툴 아닌가"라는 경계심이 있을 수 있어 포지셔닝을 "대행사가 제공하는 부가서비스 화이트라벨"로 잡아야 함.
- **숨은 타겟**: 소상공인 지원기관·상권 활성화 협의회(지역 상공회의소, 소상공인시장진흥공단 산하 프로그램) — 예산이 아니라 "레퍼런스와 신뢰"를 얻는 채널로 활용.

---

## 3. 전체 전략 구조 (왜 하이브리드가 맞는가)

소액 예산 + 1~3개월이라는 조건에서 대행사 B2B만 노리면 "제휴 논의"에 시간이 다 갈아 없어지고, 소상공인 직판만 노리면 한 곳씩 설득하느라 확산 속도가 안 나와요. 그래서 **직판 파일럿 → 증거 데이터 확보 → 그 데이터로 대행사 설득**이라는 순차 구조가 맞습니다. 대행사는 "이거 될 것 같다"가 아니라 "이미 3곳에서 재방문율 OO% 올랐다"는 숫자에 움직여요.

```
1단계: 자사 고객 파일럿 (무료/저가)
   ↓ 성과 데이터 확보
2단계: 데이터를 콘텐츠화 → 온라인 오가닉 확산 + 오프라인 상권 영업
   ↓ 신규 유료 계약 축적
3단계: 축적된 성과 사례를 무기로 대행사 B2B 제휴 제안
```

---

## 4. 오프라인 마케팅 상세 기획

### 4-1. 자사 고객 파일럿 세팅 (0주차, 최우선)
- 기존 대행사 고객 중 재방문 관리에 아쉬움을 느낀 곳 3~5곳 선정
- 조건: 1개월 무료 또는 파격 저가 제공 대신 "성과 데이터 공개 동의" 받기 (계약서에 명시)
- 세팅 시 사장님께 스크래치카드 QR을 계산대·테이블에 직접 부착까지 도와드리는 "손이 가는 온보딩"으로 초기 이탈 방지

### 4-2. 상권 오프라인 영업 (3주차~)
- 파일럿 매장 인근 상권부터 확장 (같은 상권 내 입소문 전파력이 큼)
- 명함/QR 스탠드 형태의 "재방문 전환 결과 리포트 샘플" 들고 직접 방문 — 추상적 설명보다 "OO매장 재방문율 15%→28%" 같은 숫자 한 장이 훨씬 설득력 있음
- 지역 상공회의소·소상공인연합회 지부에 무료 데모 세션 제안 (신뢰 확보용, 매출 목적 아님)

### 4-3. 소상공인 커뮤니티 오프라인 접점
- 지역 상인회 정기 모임, 프랜차이즈 점주 모임 등에 소액 스폰서/데모 부스로 참여 (비용 최소화: 유료 광고 대신 "체험 부스" 형태)

## 5. 온라인 마케팅 상세 기획

### 5-1. 오가닉 콘텐츠 (핵심, 예산 거의 안 듦)
| 채널 | 콘텐츠 방향 | 빈도 |
|---|---|---|
| 인스타그램 릴스/숏폼 | 파일럿 매장에서 스크래치카드 실제 사용 장면 + "재방문율 반전" 전후 데이터 | 주 2~3회 |
| 네이버 블로그 | "위드픽 대신 이거 써봤더니" 식 비교형 포스팅, 사장님向 SEO 콘텐츠 | 주 1회 |
| 유튜브 쇼츠 | 사장님 인터뷰형 후기 (1분 내외, 저비용 촬영) | 격주 1회 |

### 5-2. 소상공인 커뮤니티 침투 (오가닉, 저비용)
- 네이버 카페: "아프니까 사장이다" 등 자영업자 커뮤니티에 정보성 글(광고 아닌 정보 톤)로 자연 노출
- 카카오톡 오픈채팅: 지역별/업종별 사장님 오픈채팅방에 파일럿 사례 공유

### 5-3. 소액 유료 광고 (전환 임팩트 있는 곳에만 집중 투입)
- 메타(인스타/페이스북) 좁은 타겟팅: 위치(파일럿 인근 상권 반경) + 업종(요식업/미용업 사장님) 타겟, 일 예산 1~2만원 수준부터 테스트
- 네이버 파워링크: "카톡친구 마케팅", "매장 단골 관리 앱" 등 니치 키워드 소액 입찰 (경쟁 낮아 CPC 저렴할 가능성 높음 — 실제 단가는 집행 전 확인 필요)

### 5-4. B2B 대행사 채널 (3단계, 6주차 이후)
- 파일럿 성과 데이터를 1페이지 제휴 제안서로 제작 (proposal-writer 스킬 활용 가능)
- 대행사 커뮤니티(오픈채팅, 네이버 카페)에 "화이트라벨 제공 가능" 포지셔닝으로 제휴 제안
- 목표는 계약이 아니라 "미팅 1~2건" — 하이브리드 전략에서 이 단계는 3개월 내 시작만 해도 성공

## 6. 예산 배분 (예시, 소액 기준)

| 항목 | 비중 | 비고 |
|---|---|---|
| 파일럿 매장 온보딩(무료/저가 제공분 손실) | - | 현금 지출 아님, 기회비용 |
| 릴스/쇼츠 제작 (촬영·편집) | 소액 | 직접 촬영 시 0원, 외주 시 소액 |
| 메타 광고 테스트 | 40% | 좁은 타겟, 2주 단위로 성과 보고 확인 후 증액/중단 |
| 네이버 파워링크 | 30% | 니치 키워드 중심 |
| 오프라인 인쇄물(QR스탠드, 리포트 샘플) | 30% | 소량 인쇄로 시작 |

## 7. 12주 로드맵

| 주차 | 핵심 액션 |
|---|---|
| 1~2주 | 자사 고객 파일럿 3~5곳 세팅, 성과 측정 시작 |
| 3~4주 | 파일럿 데이터 1차 확보, 콘텐츠 제작 시작(릴스/블로그) |
| 5~6주 | 상권 오프라인 영업 시작, 소액 유료광고 테스트 |
| 7~9주 | 신규 유료 계약 확대, 커뮤니티 콘텐츠 확산 |
| 10~12주 | 대행사 B2B 제휴 제안서 발송·미팅 시작, 1~3개월 성과 정리 |

## 8. 미확정 사항 후보

- **가격 정책**: 월 구독형(예: 3만~9만원대) vs 성과 연동형(재방문 전환 건당 과금) — 소상공인은 고정비 부담을 싫어해서 초기엔 "저가 고정 + 성과 보고서 무료 제공"으로 시작하고, 데이터 쌓이면 성과 연동형 옵션 추가하는 방향 추천
- **B2B 제휴 구조**: 화이트라벨(대행사 브랜드로 재판매) vs 리퍼럴(소개 수수료) — 초반엔 관계 형성이 우선이니 리퍼럴로 가볍게 시작 추천
- **파일럿 매장 선정 기준**: 재방문율이 이미 낮은 매장(개선 여지 커서 극적 데이터 나옴) vs 사장님이 적극적인 매장(운영 협조 잘 됨) — 가능하면 둘 다 만족하는 곳 우선

## 9. 실행 체크리스트 (바로 시작할 것)

1. [ ] 기존 대행사 고객 리스트에서 파일럿 후보 3~5곳 추리기
2. [ ] 파일럿 계약서에 "데이터 공개 동의" 조항 추가
3. [ ] 재방문율 측정 기준(before/after) 미리 정의 — 게임 시작 전 데이터 확보해둬야 "전후 비교"가 가능함
4. [ ] 릴스 1편 촬영 계획 잡기 (파일럿 세팅 당일 촬영해두면 좋음)
5. [ ] 니치 키워드 리스트업 → 네이버 파워링크 소액 테스트 준비
