## 1. 관리자 로그인

| 항목 | 내용 |
|------|------|
| **URL** | `/admin/login` |
| **대상** | 사장님(광고주), 직원(staff), 에이전시, 최고관리자 |
| **접근 방법** | 브라우저에서 직접 URL 입력 |

### 기능
- 이메일 + 비밀번호로 로그인
- 로그인 후 역할(role)에 따라 접근 가능한 메뉴가 자동으로 결정됨
- 로그인하지 않으면 관리자 페이지 전체 접근 불가 (자동 리디렉트)

### 역할별 권한

| 역할 | 이름 | 접근 범위 |
|------|------|-----------|
| `super_admin` | 최고관리자 | 모든 매장 전체 접근 |
| `agency` | 에이전시 | 모든 매장 전체 접근 |
| `advertiser` | 사장님/광고주 | 자기 매장만 접근 |
| `staff` | 직원 | 쿠폰 검증 화면만 접근 |

### 사용법
1. URL 접속
2. 이메일과 비밀번호 입력
3. 로그인 버튼 클릭 → 이벤트 관리 화면으로 자동 이동

### 첫 계정 만들기 (최초 1회만)
계정이 하나도 없을 때만 동작하는 임시 API로 생성:
```
POST /api/admin/auth/setup
Body: { "email": "이메일", "password": "비밀번호", "role": "super_admin" }
```

## 2. 이벤트 관리

| 항목 | 내용 |
|------|------|
| **URL** | `/admin/events` |
| **대상** | 사장님(advertiser), 에이전시, 최고관리자 |
| **로그인 필요** | 예 |

### 기능
- 등록된 이벤트 목록 확인
- 이벤트 상태 표시: `진행중` (초록) / `예정` (파랑) / `종료` (회색)
- 새 이벤트 등록 버튼

### 역할별 차이
- `advertiser`: 자기 매장 이벤트만 보임
- `super_admin` / `agency`: 전체 매장 이벤트 보임 (URL에 `?storeId=xxx` 추가하면 특정 매장 필터)

### 팁
- 이벤트가 없으면 손님 게임 화면에서 "현재 진행 중인 이벤트가 없어요" 메시지가 표시됨
- 동일 매장에 `active` 상태 이벤트는 한 번에 하나만 가능 (새로 등록 시 자동 체크)

## 3. 새 이벤트 등록

| 항목 | 내용 |
|------|------|
| **URL** | `/admin/events/new` |
| **대상** | 사장님(advertiser), 에이전시, 최고관리자 |
| **로그인 필요** | 예 |

### 기능
- 이벤트명, 기간, 경품 티어 입력
- **확률 자동 계산**: 하루 예상 참여자 수 + 티어별 수량 입력하면 당첨 확률 % 자동 표시
- 합계가 100%가 되도록 자동 조정 (직접 계산 불필요)

### 입력 항목 설명

| 항목 | 설명 | 예시 |
|------|------|------|
| 이벤트명 | 손님에게 보이는 이름 | `8월 여름맞이 당근뽑기` |
| 이벤트 노출 기간 | 게임 화면에 이벤트가 보이는 기간 | `2026-08-01 ~ 2026-08-31` |
| 하루 예상 참여자 수 | 확률 계산 기준값. 일 평균 방문객 수 입력 | `50` |
| 쿠폰 사용 기간 | 발급일로부터 며칠 안에 써야 하는지 | `14` (14일 이내) |
| 경품 티어 | 꽝 포함 모든 등급 설정 | 꽝, 1000원, 10000원 |

### 경품 티어 입력 방법
1. 기본 티어 3개 제공 (꽝, 1,000원, 10,000원)
2. **총 준비 수량** 입력 → 확률 자동 계산됨
3. `+ 티어 추가` 버튼으로 등급 추가 가능
4. `이 티어 삭제` 버튼으로 불필요한 등급 삭제
5. **직원 확인 필요** 체크박스: 1만원 이상 고액 경품은 체크 권장 (직원이 수동 확인 후 처리)

### 팁
- 꽝 수량을 많이 넣을수록 꽝 확률이 높아짐 (ex. 꽝 800개, 1000원 150개, 10000원 50개)
- 하루 예상 참여자 수가 비어있으면 확률이 0%로 표시됨 — 반드시 입력할 것
- 이벤트 등록 후 손님 게임 화면에 즉시 반영됨

## 4. 성과 리포트 (사장님용)

| 항목 | 내용 |
|------|------|
| **URL** | `/admin/report` |
| **대상** | 사장님(advertiser), 에이전시, 최고관리자 |
| **로그인 필요** | 예 |

### 기능
월별 마케팅 성과를 단계별 퍼널로 시각화:

```
월 광고비 → 게임 참여자 수 → 쿠폰 발급 수 → 쿠폰 사용 수 → 재방문 손님 수 → 추가 매출 → ROI 배수
```

### 데이터 표시 방식

| 배지 | 의미 |
|------|------|
| `실측 기준 (N건)` | payment_logs에 실제 결제 데이터가 있는 경우 |
| `추정치` | 결제 데이터 없음 → store_settings 평균객단가 × 재방문수로 계산 |

> ⚠️ 실측/추정 배지는 절대 생략되지 않습니다. 데이터 신뢰성을 투명하게 표시합니다.

### 팁
- URL 뒤에 `?month=2026-08` 형식으로 월을 지정할 수 있음
- ROI가 1 미만이면 광고비 대비 손해, 1 이상이면 이익

## 5. 에이전시 대시보드 (전체 매장)

| 항목 | 내용 |
|------|------|
| **URL** | `/admin/dashboard` |
| **대상** | 에이전시, 최고관리자만 접근 가능 |
| **로그인 필요** | 예 |

### 기능
- 전체 매장의 월별 핵심 지표를 한눈에 비교
- 전체 평균 ROI 배수 — 상단에 큰 숫자로 표시 (영업 자료용)
- 매장별 참여자 수, 재방문 수, ROI 배수 테이블 비교

### 팁
- 영업 미팅 때 이 화면을 보여주면 효과적 (전체 평균 ROI가 핵심 설득 포인트)
- `advertiser` 계정으로는 이 화면 접근 불가 (본인 매장 리포트만 볼 수 있음)

## 6. 직원 쿠폰 검증 화면

| 항목 | 내용 |
|------|------|
| **URL** | `/staff` |
| **대상** | 매장 직원 · 광고주 |
| **로그인 필요** | 예 (`staff` / `advertiser`) |

### 기능
- 손님이 보여주는 코드 또는 계산대 QR 대기번호로 조회
- **모든 경품**은 당근 단골 확인 후 지급 (금액 무관)
- [확인함] → 큰 결제안내 화면 → [할인 적용 완료] 해야 사용 처리
- 다른 매장 경품 승인 시도는 403

### 손님 QR
- URL: `/checkout/[매장ID]`
- 본인 미사용 경품에 당일 대기번호(A1, A2…) 부여

## 7. 손님 게임 화면

| 항목 | 내용 |
|------|------|
| **URL** | `/play/[매장ID]` |
| **대상** | 손님 (QR 코드로 접속) |
| **로그인 필요** | 아니오 (카카오 연동 예정) |

### 기능
- QR 코드 스캔 → 로그인 없이 게임 시작
- 크레인을 좌우 드래그해서 놓으면 자동 애니메이션 후 결과 잠금
- 카카오 로그인으로 결과 공개. **하루 1회 제한은 로그인 시점에 검사** (KST 기준 자정 리셋)
- 결과: 꽝 / 쿠폰 당첨. 포인트는 매장 스위치가 켜져 있을 때만 적립

### 손님 여정
```
QR 스캔 → 게임 → 결과 잠금 → 카카오 로그인 → 결과 공개/쿠폰 → (선택)채널 안내 → 계산대 당근 확인
```

상세: `docs/손님여정_프로세스_v2.md`

### 팁
- 매장 QR 코드 URL 형식: `https://roulette-marketing.vercel.app/play/[매장ID]`
- 매장 ID는 `test-store-001` 형식 (이벤트 등록 시 설정)
- 이미 참여한 손님이 재접속하면 "오늘은 이미 참여하셨어요" 안내 표시
