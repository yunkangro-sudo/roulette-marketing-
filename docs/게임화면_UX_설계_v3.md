# 게임 화면 UX 설계 v3

**작성일**: 2026-08-15  
**확정**: 채널 안내 문구는 현재 코드 유지. 이번 주는 카피·버튼만. 라이트+그린 테마는 다음.

용어: **"내 쿠폰보관"** (`/me/points`). "럭키박스함"은 쓰지 않는다.

## 화면 순서

```
1 랜딩 → 2 게임 → 3 결과 잠금 → 4 카카오
  ├─ 이미 참여 → 4-A
  └─ 결과 공개(5) → 채널(6) → 당첨이면 당근(7) / 꽝이면 랜딩
7 [✕] → 내 쿠폰보관(8)  (로그인 유지)
7 [확인했어요] → 로그아웃 후 랜딩
```

일반 링크 `/play/{storeId}` 는 항상 랜딩. 로그인 복귀만 `?claim=1`.

## 이번 주 (카피·버튼)

1. 랜딩: `내 쿠폰보관` → `/me/points?store_id=` / `[뽑기 시작]` / `1일 1회 응모 가능` / `로그인 없이 바로 도전해 보세요!` 유지
2. 게임 플레이: 로직·온보딩 유지. 비주얼 테마는 다음
3. 결과 잠금·이미 참여: 문구 유지
4. 결과 공개: `[다음]`만 (대박/소액/꽝 동일)
5. 채널: **현재 코드 문구 유지** (`매장 소식을…` / 추가하기 / 건너뛰기)
6. 당근: `[✕]` → 쿠폰보관(로그아웃 없음). `[확인했어요]`는 로그아웃 후 랜딩
7. 내 쿠폰보관: 기존 `/me/points`에 쿠폰 리스트 추가
