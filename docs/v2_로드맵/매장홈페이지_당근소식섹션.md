# 매장 홈페이지 "⑥ 매장 소식" 섹션 — 버전2 검토 항목

**작성 기준**: 2026-09-02
**상태**: 이번 작업(매장 공개 홈페이지 확장) 범위에서 제외 — 사장님 확인 완료
**분류**: 버전2(v2) 로드맵 — 지금 버전(v1)에는 포함하지 않음

---

## 1. 배경 — 왜 제외했는가

- GPT가 작성한 "업체 공개 홈페이지 — 최종 통합본" 지시문의 ⑥번 섹션은
  "당근마켓에 이미 자동발행하고 있는 소식 데이터를 그대로 재사용"한다는 전제로 설계되어 있었다.
- 실제 코드베이스를 확인한 결과 **그런 자동발행 기능은 존재하지 않는다.**
  `daangn_url`/`daangn_click` 관련 코드는 전부 "당근 단골추가 링크 연결"과 "그 링크 클릭 통계 집계"
  용도일 뿐, 당근 비즈프로필에 소식(게시글)을 자동으로 올려주는 기능은 어디에도 없다.
  (`README.md`의 "다음 작업 추천 순서"에도 "당근 비즈프로필 실제 연동 — 딥링크 자동 연결 미구현"으로
  이미 남아 있던 항목과 동일한 맥락)
- 즉 ⑥번 섹션은 "이미 있는 걸 재사용"이 아니라 "완전히 새로운 콘텐츠 발행 시스템"을 처음부터
  만들어야 하는 항목이라, 이번 매장 홈페이지 확장 작업 범위에서는 제외하기로 사장님과 확인했다.

---

## 2. 나중에 만든다면 — 두 가지 방향

### 방향 A. 당근 비즈프로필 실제 연동 (원안에 가장 가까움)
- 당근 비즈프로필 공식 API/제휴가 열리면, 사장님이 당근에 올린 소식을 가져와 그대로 노출.
- 전제조건: 당근 쪽 공개 API 또는 제휴 계약 필요 (현재는 없음). 리서치부터 선행되어야 함.
- README에 이미 있는 "당근 비즈프로필 실제 연동" 항목과 사실상 같은 작업이므로, 그 항목이
  풀리면 이 섹션도 같이 딸려온다고 보면 됨.

### 방향 B. 자체 "매장 소식" 게시판 신설 (독립적으로 먼저 할 수 있음)
- `business_news` 같은 신규 테이블(제목, 내용, 이미지, 게시일, store_id)을 만들고,
  관리자 화면(`/admin/business-page`)에 "소식 작성" 섹션을 추가.
- FAQ/외부링크와 동일한 패턴(전체 교체 방식 CRUD)으로 구현 난이도는 낮음.
- 다만 사장님이 "짧은 글을 직접 계속 써야 하는" 운영 부담이 생기므로, 실제로 꾸준히 쓸
  사장님이 있는지 확인 후 착수하는 게 안전함 (안 쓰는 소식 섹션은 오히려 "죽은 페이지" 느낌을 줌).

---

## 3. 권장 순서

1. 방향 B(자체 게시판)를 먼저 붙이는 게 기술적으로 더 쉽고 사장님 의존도가 명확함.
2. 방향 A(당근 연동)는 당근 쪽 제휴/API 상황이 바뀌면 다시 검토.
3. 둘 다 "게임 참여/포인트/리워드 로직과는 무관한 순수 콘텐츠 영역"이라는 원칙은 계속 유지.
